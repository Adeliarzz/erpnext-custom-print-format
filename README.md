# ERPNext Custom Print Format Sales Invoice

## Deskripsi
Repository ini berisi progress pengerjaan Custom Print Format Sales Invoice pada ERPNext menggunakan HTML, CSS, dan Jinja.

## Fitur yang telah dibuat

- Custom Print Format Sales Invoice
- Header dan Footer
- Dynamic Customer Information
- Dynamic Item Table
- Variabel Jinja
- If Condition
- For Loop
- Custom Field
- Page Break
- Pagination
- QR Code
- Total Amount
- Amount in Words (Terbilang)

## Teknologi

- ERPNext
- Frappe Framework
- HTML
- CSS
- Jinja Template

## Hasil

Custom Print Format berhasil dibuat dan dapat menghasilkan invoice dengan tampilan yang lebih rapi.
